# 🏐 여름! 바다! 배구! (Summer Volley)

레트로한 여름 바닷가 배경의 2D 배구 게임입니다.
HTML 파일 하나로 동작하며, 별도의 설치나 빌드 없이 브라우저에서 바로 실행됩니다.

## 실행 방법

`index.html`을 브라우저로 열면 끝입니다.

```bash
start index.html
```

## 게임 규칙

- 공이 자기 진영 바닥에 떨어지면 상대가 1점을 얻습니다.
- 먼저 **11점**에 도달한 쪽이 승리합니다.
- 득점한 쪽이 다음 서브를 넣습니다.
- 공은 좌우 벽과 천장, 네트에 튕기며 중력의 영향을 받습니다.

## 게임 모드

| 모드 | 설명 |
| --- | --- |
| 🤖 1인용 | AI와 대결 (난이도 선택 가능) |
| 👥 2인용 | 같은 키보드로 친구와 대결 |

## AI 난이도

1인용 모드에서 세 단계 중 선택할 수 있으며, AI의 이동 속도·반응 지연·조준 오차·점프 확률이 함께 달라집니다.

| 난이도 | 특징 |
| --- | --- |
| 😊 쉬움 | 느리게 움직이고 반응이 늦습니다. 처음 플레이하기 좋습니다. |
| 😎 보통 | 적당한 속도와 반응을 가집니다. |
| 🔥 어려움 | 빠르게 움직이고 공을 정확하게 따라갑니다. |

## 조작법

### 키보드

| 동작 | 1P (왼쪽) | 2P / AI (오른쪽) |
| --- | --- | --- |
| 왼쪽 이동 | `A` | `←` |
| 오른쪽 이동 | `D` | `→` |
| 점프 | `W` | `↑` |

공통 단축키

- `Space` 또는 `P` — 일시정지 / 계속하기
- `R` — 게임 다시 시작

### 모바일

화면 아래에 터치 조작 버튼이 표시됩니다. 1인용 모드에서는 1P 버튼만, 2인용 모드에서는 양쪽 버튼이 모두 나타납니다.

## 캐릭터 이미지 교체

시작 화면에서 1P·2P 캐릭터로 사용할 이미지를 각각 올릴 수 있습니다 (선택 사항).

- 지원 형식: PNG, WebP, JPEG
- 투명 배경 PNG를 사용하면 가장 자연스럽게 보입니다.
- 이미지를 올리지 않으면 기본 도트 캐릭터가 사용됩니다.
- 업로드한 이미지는 서버로 전송되지 않고 브라우저 안에서만 처리됩니다.

## 기술 스택

- 순수 HTML / CSS / JavaScript (프레임워크·의존성 없음)
- `<canvas>` 2D 렌더링, 960×540 해상도
- `requestAnimationFrame` 기반 게임 루프와 직접 구현한 물리(중력·반발·네트 충돌) 처리
- 배경(하늘·바다·야자수·구름)과 캐릭터는 코드로 그리는 픽셀 아트
